# Игра в браузере

Код игры лежит в `game/` (Vite + TypeScript, без фреймворков). Сейчас там вертикальный срез выпуска «Город»:
пролог и глава 1 «Завязка» из пяти сцен, около 10–12 минут игры и 5–7 страниц комикса.

Как идёт выпуск:

- **Старт.** Пол, тон кожи и три карты: кем ты был, что тебя ведёт, твоя слабость. «Удиви меня» выбирает за тебя.
- **Развилка.** Следующий пустой кадр показывает карандашный эскиз встречи, на которую наведён курсор.
  Выбранная встреча прорисовывается тушью и цветом.
- **Сцена.** Варианты с шансом заранее: проверка характеристики, бой, миниигра. Неудачу можно перерисовать
  за 1 чернило, в кадре останется зачёркнутый набросок.
- **Бой на фишках.** Общая стопка твоих и вражьих фишек, план врага виден заранее. Лёгкий удар бьёт первым,
  сильный переворачивает больше, но враг бьёт первым. После победы одну вражью фишку можно оставить себе.
- **Миниигры** на карманной консоли: «Штифты» (замок) и «Поток» (взлом). Любую можно решить броском.
- **Вещи.** Находка 1 из 3 сразу надевается, видна в следующих кадрах и кладёт свои фишки в бой.
- **Наклейки.** Пачка после стража и у художницы: берёшь одну и клеишь на битку, вещь или обложку.
- **Обложка.** За выпуск до 5 звёзд, от них бумага: газетная, глянец, фольга, голограмма, вариантная.
  Сохранность 1–10 падает от урона. «Скачать выпуск» сохраняет PNG с обложкой и всеми страницами.

Чего ещё нет в картинках, игра рисует заглушкой и пишет внизу страницы, чего не хватает.

## Тексты и баланс без кода

Весь контент лежит в `game/content/*.yaml`, их можно править в любом редакторе:

| Файл | Что внутри |
|---|---|
| `city.yaml` | персонажи, пролог, бит главы, встречи с вариантами и итогами, концовки |
| `backstory.yaml` | карты предыстории: кем был, мотив, слабость |
| `items.yaml` | одежда с фишками и характеристиками, битки, вещи в карманах, список лута |
| `enemies.yaml` | враги и стражи: здоровье, фишки, вторая фаза |
| `stickers.yaml` | 10 наклеек и их эффекты |

Формат кадров и вариантов описан в начале `city.yaml`. После правки достаточно перезапустить `game.bat`
или сделать push, Pages соберёт игру заново.

## Картинки после ночной генерации

Ночной прогон сам выгружает картинки в игру (стадия `game_export`). Вручную это делается так:

```bat
comix.bat export-game
git add game/public/assets
git commit -m "Картинки для игры"
git push
```

`export-game` кладёт в `game/public/assets` уменьшенные webp и `manifest.json`: куклу героя во всех позах,
фоны, врагов, вещи, наклейки и крупные планы. Всё вместе для города весит примерно 20–40 МБ.

## Запуск на своём ПК

Нужен Node.js 22 (один раз: `winget install OpenJS.NodeJS.LTS`). Потом:

```bat
game.bat
```

Откроется браузер с игрой, правки в `game/src` подхватываются сразу.

## GitHub Pages

После каждого push в ветку `claude/project-thread-r11h4h`, если менялась папка `game/`, GitHub Actions проверяет,
что игра собирается (`.github/workflows/game-build.yml`, «Сборка игры»).

Публикует игру `.github/workflows/pages.yml` («Игра на GitHub Pages»). Окружение `github-pages` по умолчанию
разрешает публикацию только из ветки по умолчанию, поэтому этот файл работает из неё: GitHub запускает его оттуда
после каждой удачной «Сборки игры», он собирает ту же версию `game/` и выкладывает её. Для этого файл должен лежать
в ветке по умолчанию, то есть ветку игры нужно один раз влить в неё. Дальше каждый push в ветку игры публикуется сам.

Один раз в настройках:

1. **Settings → Pages → Build and deployment → Source:** выбрать **GitHub Actions**.
2. Влить ветку игры в ветку по умолчанию (pull request → Merge).
3. **Actions → «Игра на GitHub Pages» → Run workflow** на ветке по умолчанию (или любой push в `game/`).

Можно и без слияния: в **Settings → Environments → github-pages → Deployment branches** добавить правило
`claude/*`, тогда «Игра на GitHub Pages» запускается вручную прямо на ветке игры.

Игра будет по адресу `https://aleasdeck.github.io/Comix-Project/`.

Если репозиторий останется закрытым, Pages работает только на платном плане GitHub. Тогда после шага 1
добавь переменную репозитория `PAGES_ENABLED` со значением `true` (Settings → Secrets and variables → Actions → Variables).
