# Ночная генерация ассетов игры

Одна команда генерирует всё, что нужно игре для мира «Город». Список ассетов лежит в
`config/factory/city.yaml`. На ПК с 7900 XT это примерно 5–6 часов генерации и около часа нарезки слоёв на процессоре.

## Запуск

```bat
cd /d "D:\VibeProjects\Comix Project"
git fetch origin
git switch claude/project-thread-r11h4h
comix.bat ping                 :: klein и qwen должны быть «установлена»
comix.bat night --dry-run      :: план: сколько картинок и сколько примерно часов
night.bat                      :: запуск на ночь
```

Если `git switch` ругается на изменённые файлы, сначала выполни `git stash`.

Запускать лучше в обычном окне cmd, а не через Claude Code: в авто-режиме он блокирует свежий код.
Пока идёт генерация, Windows не уходит в сон. Монитор при этом может погаснуть, это нормально.

Прерывать можно в любой момент. Повторный `night.bat` продолжит с того места, где остановился:
готовые картинки не перегенерируются.

## Что делается, по порядку

| Стадия | Что | Сколько |
|---|---|---|
| hero_poses | Базы 9 новых поз для мужчины и женщины: 2 варианта по скелету + 1 только по тексту, лучший выбирается сам | ~54 |
| hero_sets | 12 вещей трёх сетов во всех 10 позах | ~216 |
| hero_emotions | 6 эмоций слоем лица (радость, злость, удивление, грусть, ухмылка, усталость) | 120 |
| world_items | 8 вещей лута города во всех позах | 160 |
| npc_faces | По 8 лиц и причёсок NPC на пол | 160 |
| hero_qa | Автопроверка: если правка задела фигуру вне своего слота, вещь перегенерируется один раз (не больше 80 за ночь) | до 80 |
| enemies, bosses | 5 врагов, 2 подручных и злодей, по 4 позы | 32 |
| weapons, props, stickers | 6 биток, 6 сюжетных вещей, 40 наклеек | 52 |
| backgrounds | 14 локаций города (9 новых) | до 61 |
| closeups | 16 крупных планов для кадров миниигр | 16 |
| hero_process | Нарезка слоёв, manifest, экспорт для страницы-гардероба | процессор |
| game_export | Картинки и manifest для браузерной игры в `game/public/assets` (см. [GAME.md](GAME.md)) | процессор |

Сначала идут все стадии klein, потом qwen: при смене модели ImageGen перезапускает ComfyUI.

## Утром

* `build\night\report.html` показывает всё миниатюрами. Зелёная рамка отмечает выбранную базу позы,
  красная отмечает слой, который не прошёл автопроверку.
* `build\night\log.txt` это полный лог, `build\night\status.json` итог по стадиям.
* Если для какой-то позы автоматически выбран плохой вариант, выбери другой и запусти снова:
  `comix.bat doll pick --gender male --pose run --candidate 1`, потом `night.bat`.
  Слои старой базы уберутся в `old\` и перегенерируются на новой.
* Чтобы картинки появились в игре на GitHub Pages: `git add game/public/assets`, commit и push.
* Можно запустить только часть: `comix.bat night --only enemies stickers` или `--skip npc_faces`.

## Модели

Для этой ночи новых моделей не нужно: всё делают klein (FLUX.2 klein 4B) и qwen (Qwen-Image-2512),
которые уже стоят в ImageGen.

Если klein 4B плохо понимает позы по скелету, запасной путь на следующую ночь такой: FLUX.2 klein 9B
(FP8 около 9,5 ГБ, плюс его текстовый энкодер) и LoRA `refcontrol_v2_poses.safetensors` из
`thedeoxen/refcontrol-FLUX.2-klein-9B-reference-pose-lora`. У 9B некоммерческая лицензия, а у 4B Apache 2.0,
поэтому для продажи игры лучше остаться на 4B.
